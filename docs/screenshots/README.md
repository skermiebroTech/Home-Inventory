# Screenshots

The README shows these. They come from a real installation with test data, so
the photographs of the mower are coloured squares and not a mower.

| File | What it shows |
|---|---|
| `dashboard.png` | The dashboard: the totals, what is new, and what needs service. |
| `item.png` | One item: photographs, components, service history, and the log. |
| `items.png` | The item list, with a thumbnail on each row. |
| `cables.png` | The cables, with the buttons that search by one end. |
| `spares.png` | The spares shelf, with a warning on a row that ran low. |
| `labels.png` | The QR labels, ready to print. |
| `phone-cables.png` | The cables on a phone. |
| `phone-spares.png` | The spares on a phone, in the dark theme. |

To take them again, sign in to a server that holds data and capture the pages
at 1440 px wide. The phone shots come from
`adb exec-out screencap -p > shot.png`.
